# NightLayer Changelog 📝

## Version 2.0.0 (Latest) - December 2024 🚀

### ✨ New Features
- **Status Indicator**: Added "Night Layer Active" text in top-left corner when overlay is enabled
- **Improved Hotkeys**: Fixed compatibility issues with standard keyboard shortcuts
- **Intuitive Controls**: Up arrow now makes screen brighter, Down arrow makes it darker

### 🔧 Improvements
- **Better Hotkey Support**: Replaced problematic "aero" keys with standard `Ctrl+Up/Down`
- **Enhanced User Experience**: More intuitive brightness controls
- **Visual Feedback**: Status indicator shows when night layer is active
- **Optimized Performance**: Improved stability and responsiveness

### 🎯 Controls (Updated)
- `Ctrl + Space` - Toggle night layer on/off
- `Ctrl + Up Arrow` - Make screen brighter (decrease overlay opacity)
- `Ctrl + Down Arrow` - Make screen darker (increase overlay opacity)
- `Ctrl + Shift + C` - Exit application
- System tray icon - Right-click for menu options

### 🐛 Bug Fixes
- Fixed hotkey compatibility issues on Windows
- Resolved keyboard library errors
- Improved system tray integration
